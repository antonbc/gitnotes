# Security Policy

## Supported Versions

GitNotes is currently pre-1.0. Security fixes target the latest commit on
`main` and the latest published release.

## Reporting a Vulnerability

Please report security issues privately by emailing the maintainer or by opening
a private vulnerability report on GitHub when available. Do not open a public
issue for vulnerabilities involving file access, path traversal, command
execution, signing, release artifacts, or secret exposure.

Include:

- Affected version or commit
- Reproduction steps
- Impact assessment
- Any proof-of-concept files or commands needed to verify safely

The project aims to acknowledge reports within 72 hours.
